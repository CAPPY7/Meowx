D. MANUAL STEPS FOR ME

1. Create an empty public repository named homebrew-meowx under CAPPY7. Add a README so it is not empty.
2. Create a personal access token that can push to that repository (contents write).
3. On https://github.com/CAPPY7/Meowx go to Settings, Secrets and variables, Actions, and add a secret named TAP_TOKEN with that token.
4. Re-run the Release workflow on tag v1.0.3, or push a new tag. The job will write Casks/meowx.rb with version 1.0.3 and sha256 a1a9be494b662d56012ddd3cb68784b074428ab5ae8df78959c8fb673732df2f.
5. On an Apple Silicon Mac with macOS 26: download the DMG, open it, drag Meowx to Applications, then System Settings, Privacy & Security, Open Anyway. Or:
   xattr -dr com.apple.quarantine /Applications/Meowx.app
6. Right-click, Open does not clear the unidentified-developer block on current macOS.

F. KNOWN LIMITS

- The app is ad-hoc signed and not notarized. macOS Gatekeeper blocks the first launch until Open Anyway or xattr.
- Stream smoothness depends on the connection. The cache cannot make a slow link instant.
- HDR is tone-mapped. Dolby Vision uses the base layer.
- Video is drawn with libmpv's OpenGL render API. Apple has deprecated OpenGL. There is no Metal render path in libmpv.
- DVD and Blu-ray folders are best effort.
- Picture-in-Picture in this app is a floating panel, not the system video PiP used by the TV app.
- Intel Macs are not supported. The build is arm64 only.
- Homebrew install does not work until the tap repository and TAP_TOKEN exist.
